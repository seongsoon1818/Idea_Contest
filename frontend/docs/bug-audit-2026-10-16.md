# 사용자·개발자 관점 버그 점검 — 2026-10-16

## 범위와 검증 방식

모바일/PC 상태 분기, 로그인 전/둘러보기/모의 계정 세션, 온라인/오프라인 상태 이벤트를 점검했습니다. 실제 앱 스크립트와 화면 컨트롤을 실행하는 인메모리 DOM 검사 835개 및 인증 규칙·데이터·이미지·세션 검사를 통과했습니다. 수정 전 소스에서도 미니 MY Esc, 다른 탭 변경 미반영, 날짜 HTML 삽입 경로를 별도 재현했습니다. 자정 스크롤과 같은 계정 재로그인 경합은 새 회귀 검사가 수정 전에 실패하는 것을 확인했습니다.

지원되는 브라우저 제어 환경이 없어 실제 휴대폰/PC 렌더링, 실제 네트워크 차단 및 최초 오프라인 접속은 브라우저로 검증하지 못했습니다. 로그인 상태도 실제 API 인증이 아닌 서버 세션 어댑터로 검사했습니다.

## 재현 후 수정

| 관점 | 문제와 재현 조건 | 수정 | 검증 |
|---|---|---|---|
| 사용자 | 상세를 읽다가 한국 시간 자정을 지나면 날짜 갱신으로 스크롤이 위로 이동 | 상세/비교/마감 목록을 갱신하되 바깥·안쪽 스크롤 보존 | 133/77px 위치가 갱신 후 유지됨 |
| 사용자 | 다른 탭에서 정보나 북마크를 바꿔도 현재 탭에는 이전 정보가 표시됨 | 동일 저장 키의 storage 이벤트 반영. 열린 입력 폼은 교체하지 않음 | 이름·저장 목록 갱신, 입력 중 비밀번호 유지 |
| 사용자 | 미니 MY 메뉴를 Esc로 닫을 수 없음 | 메뉴 닫기, 펼침 상태 해제, 아바타로 포커스 복귀 | 실제 키 이벤트 검사 |
| 개발자 | 같은 ID로 새 세션을 설정한 후 이전 로그아웃 응답이 오면 새 UI 세션도 지워짐 | 세션 변경 횟수까지 비교해 늦은 응답 거절 | 서로 다른 계정/같은 ID 재로그인, 중복·실패 요청 검사 |
| 개발자 | API에서 들어올 날짜 문자열 일부가 HTML/속성에 이스케이프 없이 들어감 | 카드 마감 텍스트·툴팁, 상세/비교 기간, 대상 요약 이스케이프 | 날짜에 HTML/따옴표를 넣어도 이미지 요소가 생성되지 않음 |

세션 경합 수정은 프론트의 표시 상태 보호입니다. 서버의 세션 무효화·쿠키 처리·계정별 권한 검사는 백엔드가 별도로 보장해야 합니다. 탭 간 변경 반영도 완료된 로컬 쓰기의 화면 동기화이며, 여러 기기의 동시 저장이나 같은 순간의 쓰기 충돌을 해결하는 서버 동기화는 아닙니다.

## 온라인·오프라인 점검

- 연결 끊김을 전혀 알려주지 않던 부분에 상태 안내를 추가했습니다. 일반 화면과 열린 팝업 모두에서 확인할 수 있습니다.
- 연결 변화 때 새로고침하지 않으며, 로그인/비밀번호 입력값과 진행 중인 화면을 보존합니다.
- 이미 실행된 앱에서는 로컬 검색·필터·북마크 동작을 유지합니다. 저장 성공은 현재 브라우저 로컬 저장 기준입니다.
- 네트워크 감지는 힌트로만 사용하며, 이 값만으로 기능을 잠그거나 학교 사이트 링크를 비활성화하지 않습니다. LAN·VPN 등에 따라 감지가 실제 인터넷 접속과 다를 수 있기 때문입니다.
- **미지원:** 인터넷 없이 처음 접속/새로고침해도 앱을 여는 기능. 현재 서비스 워커/오프라인 앱 캐시가 없으므로 별도 설계가 필요합니다.

참고: MDN Navigator.onLine — 온라인 상태 감지는 휴리스틱이며 기능 차단 대신 안내에 사용하도록 설명합니다. https://developer.mozilla.org/en-US/docs/Web/API/Navigator/onLine

## 함께 반영한 UI 수정

- 로그인 메뉴 앞 작은 자물쇠 아이콘.
- 내 정보의 트랙을 관심 분야와 동일한 테두리 태그로 표시.
- 소셜 연결 제공자 원 30 → 38px, 내부 로고 20px.
- 사용안내 볼드·아이콘 추가, HSU PICK과 함께 글자 12px로 통일.
- 저장 책갈피의 사각 배경 제거, 안쪽 색만 유지. 하단 MY PICK 숫자 배지 제거.
- 취소창은 제목 + 실행 결과 한 문장으로 축약.
- MY PAGE·MY PICK 소개와 로그인 관리의 자명한 반복 설명 제거. 공지/프로그램의 한 줄 소개는 유지하고 첫 카드와의 간격 축소. 추천 재설정의 설명은 첫 불렛으로 이동.
- 탈퇴 안내의 중복 상단 문장을 제거하되 삭제 항목과 서버 미연결 상태는 유지.

## 백엔드 연결 전에 남은 항목

1. **실제 계정 기능:** 로그인·회원가입·소셜 연결·비밀번호 변경·탈퇴는 API 미연결. 현재 인증 성공이나 삭제 완료로 표시하지 않습니다.
2. **계정별 저장:** 지금은 브라우저 저장입니다. 서버 프로필/북마크 조회·저장·오류·재시도·충돌 처리를 연결해야 합니다.
3. **실제 학교 데이터:** 현재 정적 데이터 모듈을 API로 교체해야 합니다. 각 공지의 원문 URL과 이미지 URL, 비교과 공개 정보 필드가 필요합니다. 누락 시 학교 목록/포털로 이동하는 경로가 남아 있습니다.
4. **API 검증:** 날짜 형식, 식별자, 분류, 배열 필드의 스키마 검증과 빈 데이터·오류 응답·로딩 UI가 필요합니다. 이번 이스케이프가 전체 스키마 검증을 대체하지 않습니다.
5. **실기기 확인:** iPhone 16/안드로이드 및 PC에서 키보드·줄바꿈·고정 하단바·실제 Back/Forward·오프라인 이미지 실패를 최종 확인해야 합니다.

- 모바일 상단 로고 헤더를 72px로 조정해 위아래 여유를 추가하고, 페이지 제목과 첫 콘텐츠의 간격은 모바일 24→18px, PC 17→14px로 소폭 줄였습니다.
