# 비교과프로그램 공개 목록 기반 상세 · v1.16.66

## 화면 구성

공지사항은 상세 본문을 읽는 구조를 유지하고, 비교과프로그램은 다음 정보만 짧게 표시합니다.

1. 프로그램명과 모집 상태
2. 프로그램 한눈에: 공개 목록에 있는 설명을 바탕으로 한 짧은 소개. 설명이 없으면 이 블록을 생략.
3. 핵심 정보: 신청 대상, 신청 기간, 비교과 pt, 운영 부서
4. 진행 장소·진행 방식: 공개 목록에서 확인되는 경우에만 추가
5. 세부 참여 조건과 준비사항은 스마트자기관리시스템에서 확인하도록 안내
6. 공식 사이트 이동, MY PICK 저장, 뒤로가기

긴 본문, 준비물, 세부 활동이나 효과를 자동으로 만들어 붙이지 않습니다. 소개를 읽을 수 없는 경우 제목만으로 세부 내용을 추정하지 않습니다. 현재는 AI API를 연결하거나 스마트자기관리시스템을 추가 수집하지 않았으며, 전달받은 짧은 소개를 최대 180자까지 표시합니다. 목록 설명이 단순한 제목 반복이면 서버/기획에서 소개를 생략해도 됩니다.

## 백엔드와 합의할 데이터 구조

아래는 프론트가 지원하는 제안 구조이며, 아직 확정된 서버 API 명세가 아닙니다.

```json
{
  "id": "stable-program-id",
  "type": "program",
  "originalUrl": "https://hsportal.hansung.ac.kr/",
  "publicInfo": {
    "summary": "공개 목록에서 확인한 짧은 프로그램 소개",
    "audience": "확인된 신청 대상",
    "applicationPeriod": "확인된 신청 기간",
    "points": 20,
    "department": "확인된 운영 부서",
    "location": null,
    "format": null
  }
}
```

| 필드 | 전달 규칙 |
|---|---|
| summary | 공개 목록에 설명이 있을 때만 전달. 추측으로 목적·효과·준비물 생성 금지 |
| audience | 목록에 확인된 대상 조건만 전달 |
| applicationPeriod | 확인된 날짜·시간 그대로 전달. 목록에 시간이 없으면 23:59로 만들어 넣지 않기 |
| points | 확인된 수치만 숫자 또는 숫자 문자열로 전달. 미확인은 null |
| department | 실제 운영 부서가 확인될 때만 전달 |
| location / format | 확인되는 경우에만 전달. null이면 행 자체 생략 |
| originalUrl | 수집·접근이 허용된 실제 원문 주소가 있을 때 전달. 없으면 해당 시스템 첫 화면으로 연결 |

`publicInfo`를 전달하면 이 객체만 상세/비교 화면의 근거로 씁니다. 비어 있는 `{}` 또는 `null`을 전달해도 기존 풍부한 데이터로 빈칸을 보충하지 않습니다. 핵심 정보의 누락은 '원문 확인', 소개·장소·방식 누락은 생략합니다. 기존 정적 데이터와의 호환을 위해 `publicInfo` 속성 자체가 없는 항목만 기존 제목/짧은 소개/대상/기간/pt/부서를 사용합니다.

프론트는 프로그램에 '공지 내용 보기'와 재구성한 긴 원문을 제공하지 않습니다. 프로그램의 예전 `#source/...` 링크도 간략 상세로 이동합니다. 비교 화면에서도 프로그램은 공개 핵심 정보를 사용합니다.

## 목록/추천과 연결할 때

- 카드·D-day·대상 판정에 필요한 기존 구조화 필드도 공개 목록의 동일한 근거에서 채웁니다. 확인되지 않은 학년·트랙·기한을 임의로 생성해서 추천하지 않습니다.
- 미확인 조건과 실제 '전 학년 / 트랙 무관'은 다른 의미이므로 서버 어댑터에서 구별해야 합니다. 현재 정적 데이터의 `grades`/`tracks` 필드에 미확인 값을 억지로 매핑하지 않습니다.
- 추천 결과는 기본적으로 모집중만 보여주되 체크를 해제하면 동일한 대상 조건의 마감/예정 항목도 조회합니다. 서버 추천 API도 이 범위를 지원하도록 합의가 필요합니다.
- 공개 목록 외 제한된 경로, 로그인 세션, 비공개 토큰 API를 추가 수집하는 방식으로 빈 정보를 채우지 않습니다.

## 학생 관점 UX 수정

- 저장된 마감/예정 항목이 '모집중' 필터로 숨겨진 경우 개수와 보기 버튼을 제공. 필터 기본 체크는 유지.
- 정보 미입력 시 홈 요약 카드의 '맞춤 PICK!'을 '모집중인 기회'로 표시.
- 기존 정보 수정은 원래 화면으로 복귀. 최초 입력은 추천 홈으로 이동.
- 입력 중 닫기/앱 내부 이동/브라우저 뒤로가기로 나가면 수정 취소 확인. '계속 입력하기'는 초안 보존, '수정 취소'는 기존 저장값 유지.
- 실제 공지 원문 주소가 전달되면 해당 항목으로 이동. 현재 정적 항목에는 실제 상세 주소가 없어 학교 목록으로 연결되는 경우가 남아 있음.
