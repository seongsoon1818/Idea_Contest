# 한성 PICK UI 검토 및 반영 — 2026-10-16

## 이번 반영

| 영역 | 확인한 문제 | 반영 |
|---|---|---|
| 첫 사용 | 추천·저장·실제 신청의 차이를 알기 어려움 | 내 정보 → 맞춤 추천 → MY PICK 3장 안내, 건너뛰기, MY PAGE에서 다시 보기 |
| 관리 메뉴 | 설명과 작은 버튼이 분산됨 | 하나의 카드 안에 두 행. 제목·짧은 설명·화살표. 행 전체 터치 |
| 재설정/탈퇴 | 결과를 실행 전에 알기 어려움 | 팝업으로 유지/삭제 범위 설명. 계정 서버 미연결 상태에서는 탈퇴 완료 처리 없음 |
| 로그인 상태 | 이름 입력과 인증 상태를 혼동할 수 있음 | 서버 세션 어댑터 기준으로 로그인(파랑)/로그아웃(빨강) 분기 |
| 내 정보 | 일반적인 질문과 길어진 완료 버튼 | ‘나에 대해 알려주세요!’ 및 이름 기반 관심 분야 질문. ‘PICK 보기’로 축약, 하단 학년/트랙 요약 제거 |
| 팝업 모션 | 전환을 인식하는 단서 부족 | 처음 열 때 200ms/10px 등장, 안내 내용 전환 180ms/4px. 모션 줄이기 시 비활성화 |
| 저장 피드백 | 빈번한 작업에는 확인창이 과도함 | 기존 저장 토스트 유지. 새 확인 팝업 추가하지 않음 |
| 가입 안내 | 기존 #8390a4/흰색 대비 약 3.24:1 | 같은 회색 계열 #59677e로 조정, 흰색 대비 약 5.73:1 |
| 터치 영역 | 북마크 36×36, 비교 높이36 | 북마크 최소44×44, 비교 높이44로 확대. 아이콘 그림 크기 유지 |

모션 시간과 거리는 이 앱에 맞춘 설계 값이며 외부 가이드의 필수 수치는 아닙니다. 44px는 WCAG의 강화(AAA) 목표를 참고한 개선이며, 기존 36px가 곧 AA 위반이라는 뜻은 아닙니다. 대비는 CSS의 단색과 흰 배경을 사용한 계산이며 화면 합성 전체를 측정한 결과는 아닙니다.

## 추가 권장 사항

1. **백엔드 로딩·실패·재시도 UI**: API가 붙으면 첫 목록에는 카드 뼈대, 저장에는 처리 중 상태, 실패에는 같은 위치의 재시도를 연결합니다. 지금은 가짜 지연을 넣지 않았습니다. 실패 시 저장 상태를 되돌리는 계약도 필요합니다.
2. **작은 카테고리 글씨**: 모바일 11px 구간은 읽기 어려울 수 있습니다. 사용자가 정한 두 줄 배치를 유지하며 12px 이상을 실기기에서 비교하는 것이 다음 순서입니다. 이번에는 기존 카테고리 배치·크기·색을 임의 개편하지 않았습니다.
3. **긴 트랙 선택과 짧은 확인 분리**: 트랙 검색은 현재 큰 선택창을 유지하고, 재설정·삭제 확인은 짧은 설명과 두 개 이하의 주요 선택으로 유지하는 것이 적절합니다. 모든 행동에 팝업을 추가하지 않습니다.
4. **문맥 안내**: 비교 기능을 처음 선택했을 때만 ‘2개 이상 선택하면 비교’와 같은 안내를 보여주면 3장 안내의 암기 부담을 줄일 수 있습니다. 현재 비교 트레이에 필요한 선택 수가 표시됩니다.
5. **로그인 관리**: 실제 연동 시 소셜 연결 상태(연결됨/연결하기)와 로그인 방식별 비밀번호 변경 가능 여부를 표시해야 합니다. 현재 서버 미연결 안내를 유지하며 연결 완료처럼 표시하지 않습니다.

## 참고 자료와 채택한 원칙

- Apple HIG, Onboarding: 짧고 선택 가능한 안내, 실제 사용 맥락의 도움말. https://developer.apple.com/design/human-interface-guidelines/onboarding
- Material Design 3, Lists: 제목·보조 설명·후행 요소로 행을 구성. https://m3.material.io/components/lists/overview
- W3C WCAG 2.3.3 (AAA): 불필요한 인터랙션 모션을 끌 수 있게 함. https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html
- W3C WCAG 2.5.5 (AAA): 44×44 CSS px의 강화 터치 목표. https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html
- W3C WCAG 1.4.3 (AA): 일반 텍스트 4.5:1 대비. https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html

## 검증 범위

실제 앱 코드를 실행하는 인메모리 DOM 흐름 검사로 모바일/PC 상태 분기, 첫 진입/건너뛰기/이전/완료/다시보기, 이름 기반 질문, 관리 메뉴, 인증 상태 분기 및 기존 기능을 검사했습니다. 별도 세션 어댑터 검사로 실패·중복 요청·계정 변경 처리를 확인했습니다. 이 환경에 지원되는 브라우저 제어 도구가 없어 실기기 렌더링, 스크린샷, 애니메이션의 시각적 품질을 확인한 것은 아닙니다. 실제 인증·연결·탈퇴·계정별 저장은 백엔드 연동 후 검증이 필요합니다.

## 추가 반영 (v1.16.71)

- 온보딩에 AI 비교하기를 마지막 장으로 추가하고, 첫 방문에서는 로그인 전에 표시합니다. 시작하기/건너뛰기 이후 로그인으로 이동합니다. 모바일은 화면 전체를 사용합니다.
- 이용 안내를 번호·아이콘·짧은 설명의 네 가지 카드로 재구성하고 브라우저 저장 박스를 제거했습니다. 하단 로그인 링크도 삭제했습니다. 실제 서버 저장 연결은 별도입니다.
- 로그인 관리도 ‘추천 및 계정 관리’와 동일한 제목·설명·행 높이·여백 구조로 정리하고 소셜 제공자 아이콘은 유지했습니다. Material 3의 제목/보조 설명/후행 요소 구성 참고입니다.
- 내 정보 수정 버튼은 카드 하단 오른쪽에 배치했습니다. 1단계 상단의 ‘내 정보’ 라벨과 설명의 ‘한성픽이’를 제거했습니다. 단계 숫자는 유지했습니다.

- 내 정보 카드도 제목을 밖에 두고, 읽기 전용 정보 행에 동일한 제목/보조 정보 간격과 내부 여백을 적용했습니다. 수정 버튼은 하단 오른쪽에 유지합니다. 관심 분야 단계의 이전 버튼은 76px, PICK 보기에는 남는 폭을 배정하고 별 아이콘을 앞으로 옮겼습니다.
