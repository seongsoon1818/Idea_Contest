# 백엔드 연동 전 프론트엔드 점검 · 2026-10-16

## 현재 상태

프론트는 `dist/`의 정적 HTML/CSS/ES module JS입니다. React 프로젝트가 아닙니다. 이 수정본은 실제 인증·API를 연결하지 않습니다. 로그인/회원가입 화면은 입력 검사만 수행하며, 계정 생성·로그인 성공·소셜 연결·비밀번호 변경·탈퇴 완료를 가짜로 처리하지 않습니다. 현재 데이터는 `dist/data.js`, 내 정보와 북마크는 `hsupick-v1` 브라우저 저장값을 사용합니다. 로그인 필수 전환은 서버 세션 확인을 연결한 다음 진행합니다. 기존 로그인 필수 초안 v1.16.60에는 이번 버그 수정이 없으므로 그대로 덮어 배포하지 말아야 합니다.

브라우저 기록과 팝업 복귀 로직도 화면 크기와 관계없이 공유합니다. 이름, 트랙 초안은 화면 기록에 포함되지만 비밀번호는 포함하지 않습니다.

## 성진님과 확정할 API 계약 (아래는 요구사항이며 구현된 API 명세가 아님)

1. **접속 환경**: 운영/개발 API base URL, HTTPS, 프론트 도메인 CORS 허용, 쿠키/세션 방식 및 CSRF 처리, 로그인 만료 응답.
2. **계정**: 아이디 로그인, 이름 포함 회원가입, 중복 아이디 오류, 아이디/비밀번호 찾기의 본인 확인 수단, 세션 조회/로그아웃, 비밀번호 변경/탈퇴.
3. **소셜**: 카카오·구글 로그인 시작/콜백 URL, 기존 계정 연결/해제, 이미 연결된 계정 충돌 규칙. 제공자 비밀 키는 서버에만 보관.
4. **프로필**: 이름, 학년(1~4/기타), 순서가 있는 1·2·3트랙, 관심 분야. 1학년은 1트랙에서 대학·학부·학과만 선택하고 2·3트랙은 받지 않음. 2학년 이상/기타는 1·2트랙 필수, 3트랙만 선택 공란 지원. 공란을 제거해 트랙 번호를 당기지 말 것. 트랙/학과는 서버의 안정적인 ID와 표시명을 함께 주고 프론트 카탈로그와 매핑.
5. **목록/상세**: 안정적인 공지 ID, 유형, 카테고리 ID, 제목, 요약, 원문 URL, 부서, 신청 시작/마감, 대상 학년·트랙, 혜택, 준비사항, 이미지 URL/대체 설명. 날짜/시간대는 Asia/Seoul 기준으로 명확히 정의. 기재 없는 항목은 null/빈 배열로 전달하고 임의로 만들어 채우지 말 것.
6. **추천**: 추천 대상 판정·순위·이유를 서버에서 줄지, 프론트의 현재 규칙을 유지할지 확정. 모집중 해제 시 추천 결과 범위 및 페이지네이션의 전체 개수 계약도 확정.
7. **북마크**: 계정별 조회/추가/해제. 반복 저장/해제의 결과가 일관되도록 처리. 다른 계정의 북마크 접근은 서버에서 차단.
8. **오류**: 성공/입력 오류/인증 만료/권한 없음/중복/요청 제한/서버 오류의 상태 코드와 필드별 메시지 형식.

## API를 받은 후 프론트에서 반드시 연결할 작업

- 세션 조회 완료 전 인증 상태 확인 UI → 성공 시 계정별 데이터 조회 → 실패 시 로그인. 현재 둘러보기 세션 플래그를 인증으로 사용하지 않기.
- `data.js` 직접 의존을 API 데이터 어댑터로 교체. 잘못된/누락된 데이터 검증, 알 수 없는 카테고리와 빈 날짜 처리.
- 현재 날짜만 있는 신청 마감 계산을 실제 마감 시각 계약에 맞추기. 서버가 18시 마감처럼 시각을 주면 23:59로 고정하지 않기.
- 공식 홈페이지 첫 화면 대신 항목별 실제 원문 URL 연결. URL은 허용된 HTTPS 주소인지 검증.
- 목록·상세·저장 요청에 로딩/실패/재시도/빈 결과 UI 추가. 요청 중 중복 클릭 방지, 늦게 도착한 이전 검색 응답 취소 또는 무시.
- 북마크 저장 실패 시 기존 상태 복원. 로그인 만료 시 미완료 동작을 구분해 안내.
- 로그아웃/계정 변경 시 이전 사용자의 프로필·북마크·비교·화면 기록을 제거. 기존 브라우저 데이터는 사용자 동의 없이 계정에 덮어쓰지 않기.
- 계정 연결 후 브라우저 로컬 초기화 기능과 브라우저 저장 안내를 제거하거나 새 의미로 수정. '추천 정보 다시 설정'과 '회원 탈퇴'는 구분 유지.
- 아이디 규칙은 영문·숫자 4~20자, 비밀번호는 영문·숫자·ASCII 기호 각 1개 이상 8~32자이며 한글/공백 불가. 서버도 재검증. 아이디 대소문자 구분 여부는 합의 필요.

## 검증 범위와 남은 수동 확인

`npm run check`: 문법 검사, 인증 입력 경계, 이미지 URL, 분류/추천 검사, DOM 동작 회귀 검사 통과. 이 테스트는 메모리 DOM이며 실제 CSS 레이아웃·렌더링을 검증하지 않습니다.

이 환경에는 지원되는 브라우저 제어 기능이 없어 실제 iPhone/PC 화면 검증을 실행하지 못했습니다. API 연결 전후에 320/393/430/768/1280/1440px, 키보드 열린 상태, 200% 글자 확대, 긴 이름·트랙·제목, 이미지 로딩 실패, 직접 링크 진입, Back/Forward, 소셜 콜백 복귀를 실제 브라우저에서 확인해야 합니다. 특히 모바일 카테고리의 두 줄 배치와 메인 배너 그림 잘림은 픽셀 화면 확인이 필요합니다.

### 1학년 트랙 규칙 수정 (v1.16.63)

모바일/PC 모두 1학년은 1트랙만 표시·저장합니다. 다른 학년에서 1학년으로 바꾸면 2·3트랙 값을 제거합니다. 이전 브라우저 저장값에 남아 있던 1학년의 2·3트랙도 화면과 추천에 사용하지 않습니다. 2학년 이상/기타는 1·2트랙을 필수로 선택하며 3트랙만 선택 항목입니다. 서버도 1학년의 불필요한 2·3트랙 값을 수락하지 않도록 계약에 반영해야 합니다.

### 학생 관점 UX 개선 (v1.16.66)

저장된 마감·예정 항목 보기, 추천 모집중 체크 해제의 실제 동작, 개인화 전 홈 문구, 정보 수정 후 복귀, 초안 취소 확인을 개선했습니다. 비교과 간략 상세와 백엔드 공개 정보 전달 계약은 `docs/program-public-content.md`를 참고하세요.
