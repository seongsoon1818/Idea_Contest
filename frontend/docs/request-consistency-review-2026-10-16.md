## 2. 이번 카테고리 보완

사용자가 제공한 사진은 첫 줄에 ‘전체·학사·비교과·장학지원·창업’, 둘째 줄에 ‘진로취업·현장실습·국제교류’가 있습니다. 창업을 옮긴 모바일 공지 PICK 순서는 다음과 같습니다. 표시명과 색은 유지합니다.

| 줄 | 순서 |
|---|---|
| 1 | 전체 → 학사 → 비교과 → 장학·지원 |
| 2 | 진로·취업 → 현장실습 → 국제·교류 → 창업 |

- 첫 줄 버튼은 글자 길이에서 나온 원래 폭의 비율을 유지하며 카드의 양쪽 끝에 맞춥니다.
- 둘째 줄에도 같은 확대 비율을 우선 적용합니다. 둘째 줄이 더 길면 자체 가용 폭에 맞춰 확대 비율을 제한하므로 세 번째 줄로 밀리지 않습니다.
- 버튼 높이·폰트 크기·색·분류 내용은 유지하며, 명시적인 두 줄 컨테이너를 사용합니다. 비교과 PICK에도 같은 폭 계산을 사용합니다.
- 극도로 좁은 화면이나 글자 확대에서 원래 글자 폭조차 들어가지 않으면, 잘라내거나 글씨를 찌그러뜨리는 대신 줄바꿈을 허용합니다. 모든 폭/접근성 확대 상태에서 두 줄을 보장하는 방식은 아닙니다.
- 실제 폰트 로딩 완료와 창 크기 변경 시 다시 계산합니다. 실제 렌더링·가로 오버플로는 실기기 확인이 필요합니다.

## 4. 검증과 남은 한계

- `npm run check` 통과: **909개 인메모리 DOM 흐름 검사** 및 데이터 경계·세션·입력 규칙·이미지·추천 검사.
- 현재 소스를 실행하는 인메모리 DOM 회귀 검사로 검색·필터·북마크·상세·추천·계정 관리·온보딩·화면 크기 전환을 확인합니다.
- 폭 계산은 첫 줄 양 끝 맞춤, 더 긴 둘째 줄의 최대 폭 제한, 원래 폭 미만으로 축소하지 않기, 좁은 화면의 안전한 줄바꿈을 별도 검사합니다. 이는 브라우저의 폰트 측정과 레이아웃 검사를 대신하지 않습니다.
- CSS 블록 균형과 모든 자간 선언의 공통 토큰 사용, JS 문법 및 기존 기능 회귀를 확인합니다.
- **미확인:** iPhone 16/안드로이드/PC에서 실제 픽셀 화면, 확대 글꼴, 짧은 창에서의 온보딩 스크롤, 키보드와 하단바 간섭, 외부 이미지 서버 및 실제 API/소셜 인증.
- 실제 계정 기능·서버 프로필/북마크·학교 목록 API는 여전히 별도 연결이 필요합니다. `prelaunch-review-2026-10-16.md`의 연동 미완료 항목은 그대로 유효합니다.
