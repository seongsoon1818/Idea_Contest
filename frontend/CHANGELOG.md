# 변경 기록

## 1.17.0 — 2026-10-28 · 알림 기능 추가

알림 관련 변경을 하나의 독립 커밋으로 묶었습니다. [추가·수정 파일 안내](docs/notification-changes-2026-10-28.md)를 먼저 읽어주세요.

### 추가
- 상단 종 아이콘, 알림함, 미읽음 표시, 개별 읽음/모두 읽음.
- MY PAGE의 마감 알림/맞춤 알림 독립 설정과 브라우저 푸시 연결 UI.
- 마감 알림 공지당 1회, 새로운 맞춤 소식만 하루 1회 묶음 처리 정책.
- 알림 종류별 상세/추천 목록 이동, Web Push 서비스 워커, 서버 어댑터 연결 지점.
- 알림 정책·계정 분리·중복 방지·서비스 워커 검사, 모바일/PC DOM 흐름 검사.

### 서버 연동 필요
- 알림 DB, 실제 계정별 기록/설정 동기화, 오전 9시 예약 작업, VAPID 비밀키/푸시 발송.
- 계정별 구독 연결/로그아웃 해제, 여러 기기 및 여러 서버 작업자의 중복 방지.
